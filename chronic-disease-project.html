Project Overview

This project involved developing an interactive dashboard using Microsoft Power BI to explore chronic disease and health-related indicators across U.S. states. The dashboard analyses data covering the period 2019–2023 and allows users to explore different health indicators and compare results across states.

Dashboard Preview

The dashboard presents health-related information through interactive visualisations, KPI cards, filters and data tables.

Tools and Technologies

Microsoft Power BI Data Cleaning Data Visualisation Dashboard Design

My Dashboard Contributions

The following visualisations highlight some of the dashboard components I personally developed as part of this group project.

1. Shape Map

Created a Shape Map to display health indicator values across U.S. states, allowing users to compare geographical differences.

2. Top 10 Areas by Rate

Developed a dynamic Top 10 table that displays the ten highest-rate areas based on the selected health indicator.

3. Indicator Slicer

Developed an indicator slicer that allows users to select different health indicators and explore the corresponding dashboard results.

Dashboard Features

  • Interactive Slicers: State, year, value type and indicator filters for exploring the dashboard data.
  • Key Performance Indicators (KPIs): Overall adult rate, highest-rate area, lowest-rate area, highest-rate ethnic group and lowest-rate ethnic group.
  • Geographical Visualisation: Shape Map displaying health indicator values across U.S. states.
  • Dynamic Data Table: Top 10 areas ranked by rate based on the selected indicator.
  • Trend Analysis: Combined column and line charts for exploring health indicator patterns.
  • Comparative Visualisations: Bar and area charts for comparing health-related data.
