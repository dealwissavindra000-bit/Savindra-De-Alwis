Project Overview

This project involved developing an interactive dashboard using Microsoft Power BI to explore chronic disease and health-related indicators across U.S. states. The dashboard analyses data covering the period 2019–2023 and allows users to explore different health indicators and compare results across states.

Dashboard Preview

The dashboard presents health-related information through interactive visualisations, KPI cards, filters and data tables.

Tools and Technologies

Microsoft Power BI Data Cleaning Data Visualisation Dashboard Design

My Contributions

As a member of the project team, I contributed to several aspects of the dashboard's development, including data preparation, visualisation and layout.

  • Created a dynamic Top 10 table showing the highest-rate areas based on the selected indicator.
  • Created the Shape Map to display indicator values across U.S. states.
  • Developed the indicator slicer for interactive filtering.
  • Cleaned and prepared data by removing unnecessary data, renaming columns and changing data types.
  • Designed dashboard elements, including the title bar and text bar.
  • Created one of the five KPI cards, displaying the highest-rate ethnic group percentage.

Dashboard Features

  • Interactive indicator selection.
  • State-level data visualisation using a Shape Map.
  • Dynamic Top 10 table.
  • KPI cards displaying key figures.
  • Charts and tables for exploring health-related data.
